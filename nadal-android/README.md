# Move Nadal

El projecte conté la pàgina de Nadal (`public/plantilla-evento.html`) i una versió de l'app en desenvolupament (`public/nadal-app.html`). El disseny i les funcionalitats de l'app encara requereixen revisió abans de publicar-la.

Per preparar Android, instal·la les dependències d'aquesta carpeta amb `npm install` i executa `npm run android:sync`. Obre `android/` a Android Studio per compilar una versió de prova. Cal un JDK compatible i l'Android SDK. No hi ha cap APK generat en aquest repositori.

L'app empaquetada apunta inicialment a l'API de proves de Move. L'enviament de propostes per correu requereix configurar el servidor i desplegar-hi els canvis corresponents; no està garantit en aquesta versió. La carpeta de servidor no s'inclou en aquesta branca.
